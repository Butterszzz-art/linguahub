The Futur Simple

The futur simple is the true "will do" future tense — more formal/written than the futur proche (aller + infinitive) from Lesson 13, but essential for plans, predictions, and promises.

Grammar

  • Formation: infinitive (for -er and -ir verbs) or infinitive minus final -e (for -re verbs) + these endings, which are the SAME for every verb in French: -ai, -as, -a, -ons, -ez, -ont. (Notice these look like the present tense of avoir — a helpful memory trick.)
    parler -> je parlerai
    finir -> je finirai
    vendre -> je vendrai (drop the final -e first)
  • Many common verbs have an irregular STEM (but still use the same regular endings): être -> ser-, avoir -> aur-, aller -> ir-, faire -> fer-, venir -> viendr-, voir -> verr-, savoir -> saur-, pouvoir -> pourr-, vouloir -> voudr-, devoir -> devr-, falloir -> il faudra (impersonal).
  • Use futur simple for: predictions, promises, and formal plans, and ALWAYS after "quand/lorsque/dès que/aussitôt que" (when/as soon as) when the main clause is also about the future — unlike English, which uses present tense after "when" for future events: Quand j'arriverai, je t'appellerai. (When I arrive [lit. "will arrive"], I'll call you.)

Reference Table

parler (to speak) — futur simple:
je parlerai         nous parlerons
tu parleras          vous parlerez
il/elle/on parlera    ils/elles parleront

être / avoir / aller / faire — futur simple stems:
je serai / j'aurai / j'irai / je ferai

Examples

L'année prochaine, nous irons en France.

Next year, we'll go to France.

Je te téléphonerai dès que j'arriverai.

I'll call you as soon as I arrive. (both verbs in futur simple, unlike English)

Il fera beau demain.

It will be nice out tomorrow.

Elle sera médecin dans cinq ans.

She will be a doctor in five years.

Notes

  • Common mistake: using present tense after "quand" for a future event, as English does. In French this MUST be futur simple on both sides: "Quand je serai grand..." (When I grow up..., lit. "will be").
