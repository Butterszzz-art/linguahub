HOW THIS COURSE IS ORGANIZED
-----------------------------
This is a full beginner-to-intermediate Italian curriculum, split across 5
content files so each one is a manageable size for import into your webapp.
Every file uses the same plain-text structure so it can be parsed
programmatically:

  ################  = PART divider (top-level unit)
  ================  = LESSON divider (one lesson/topic)
  ALL-CAPS LABEL:    = section within a lesson (OVERVIEW, GRAMMAR,
                       CONJUGATION TABLE, VOCABULARY, EXAMPLES, NOTES,
                       PRACTICE)

Suggested parsing rule for your webapp: split on lines of "====" to get
lessons, then split each lesson on the ALL-CAPS labels followed by a colon
at the start of a line to get sections.

Pronunciation convention: Italian pronunciation is written phonetically in
parentheses right after each word, syllables separated by hyphens, with the
STRESSED syllable in CAPITALS — e.g. casa (KAH-zah) (house). This differs
slightly from italics-for-stress used in some textbooks, but capitals are
easier to render as plain text in a webapp.

RECOMMENDED PATH
-----------------
Beginner:      Part 1 -> Part 2 -> dip into Part 3 for food/shopping vocab
Intermediate:  Part 3 -> Part 4 (this is where the past, future, and
               imperative tenses come in)
Advanced:      Part 5 -> polish weak spots, start reading/media, layer in
               the idiomatic expressions

Each lesson is self-contained enough to stand alone as a "classroom" unit —
overview, rule explanation, a reference table, core vocabulary, worked
example sentences, and common-mistake notes, in that order.

A NOTE ON SOURCES
-------------------
All explanations, example sentences, and dialogues in this course were
written originally for this curriculum. The source textbook was used only
to determine which topics to cover, in what order, and to keep vocabulary
choices and phonetic conventions authentic to how the book teaches Italian
pronunciation (hyphenated syllables, e.g. buongiorno (bwohn-JOHR-noh)).
